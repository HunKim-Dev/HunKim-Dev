### 안녕하세요, 프로덕트 개발자 김태헌입니다

사용자의 문제에서 출발해 제품을 만들고, 출시 후에도 계속 개선합니다. 웹, 3D 인터랙션, AI 에이전트 중 문제에 맞는 기술을 골라 씁니다.

- 퇴근 후 반려견과 다녀올 근교 외출지를 시간 기준으로 추천하는 댕로드로 한국관광콘텐츠랩 공모 본선에 올랐고, 팀과 함께 제품을 개선하고 있습니다.
- 스크립트 한 줄로 홈페이지에 설치하는 소상공인용 RAG 기반 AI 안내원 챗봇 Desker AI를 팀으로 만들었습니다.
- 웹캠 손 제스처로 브릭을 집고 조립하는 3D 레고 시뮬레이터 MotionBricks를 만들어 배포했습니다.
- 개발하면서 반복되는 문제는 도구로 해결합니다. 스펙과 디자인을 마크업으로 바꾸는 Markup-agent와, 프로젝트 지식을 쌓고 답변 근거를 검증하는 Wiki를 Claude Code 위에 만들어 쓰고 있습니다.
- 주어진 문제는 끝까지 책임지고, 팀에서는 문제의 원인과 방향을 공유하며 의견 차이를 조율해 공통된 해답을 만들어가는 과정을 중요하게 생각합니다.
